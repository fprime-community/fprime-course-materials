# F´ Course Materials

This repository contains the materials prepared for various courses taught using F´. The classes
are designed to improve the community surrounding F´ and help users improve.

## Flight Software Workshop

The flight software workshop is designed to give a primer on Flight Software.  The course is taught around F´ as a model for flight software.


## Advanced F' Workshop

This 2-day workshop builds upon the introductory Flight Software Workshop, focusing on more advanced software development concepts using the F Prime framework.

Topics include:

- Creating F Prime Projects

- Common Design Patterns In F Prime

- Contributing to F Prime

- Advanced Modeling in FPP (State Machines, Subtopologies, and Custom Autocoders)

- Advanced Testing Approaches

- Participation in one of the lab assignments, such as
    - Advanced Topology Development Through Communications Drivers
    - Advanced Modeling Through State Machines
    - Data Products
    - Configuring F Prime for Small Scale Systems

Pre-requisites:
    - Complete the [hello-world tutorial](https://github.com/fprime-community/fprime-tutorial-hello-world)
    - Complete the [LED Tutorial](https://fprime.jpl.nasa.gov/latest/tutorials-led-blinker/docs/led-blinker/)
