# F´ Course Materials

This repository contains the materials prepared for various courses
taught using F´. The classes are designed to improve the community
surrounding F´ and help users improve.

## Flight Software Workshop - February 2026

The flight software workshop held in February 2026 is designed to give
a primer on Flight Software. The course is taught around F´ as a model
for flight software.
